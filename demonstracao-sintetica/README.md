# Demonstração CAD sintética

Aplicação didática independente com um painel de configuração fictícia. Não representa os desenhos, o código nem as saídas do projeto descrito no estudo de caso na raiz do repositório.

Roda com `python server.py` e abre em `http://127.0.0.1:8765`. O parser usa regras locais; não chama IA. As sete folhas são exemplos visuais sintéticos e não têm finalidade de dimensionamento ou fabricação.

Para conhecer o trabalho real de automação CAD e 3D em nível anonimizado, volte ao [estudo de caso](../index.html).
